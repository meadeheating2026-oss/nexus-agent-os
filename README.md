# Nexus AgentOS — نظام تشغيل الوكلاء الذكيين اللانهائي

منصة ونظام تشغيل مفتوح لبناء وإدارة وتشغيل **عدد لا نهائي من وكلاء الذكاء الاصطناعي** في أي مجال، مع دعم التشغيل المستقل (Standalone) والتكامل الجماعي بين الوكلاء (Multi-Agent Swarm)، وحوكمة مالية آلية لتعظيم الربح (Internal Profit + Multi-Tenant SaaS).

## المميزات الأساسية
1. **مصنع وكلاء بلا حدود (`Agent Studio`)**: أضف أي عدد من الوكلاء (100+ وكيل أو أكثر) في أي قطاع جديد يدوياً أو عبر المولّد الذكي للوكلاء (`Meta-Spawner`).
2. **مخزن ومنشئ الأدوات (`Pluggable Tool Registry`)**: أدوات مدمجة للبحث وسحب المواقع وتحليل الكود والذاكرة، مع إمكانية إضافة أي أداة `REST API` أو `Webhook` لأي مجال جديد من داخل الواجهة.
3. **التكامل الذاتي وغرفة العمليات (`Mission Control`)**: تشغيل فردي مستقل أو دمج عدة وكلاء في خلية عمل مترابطة مع بوابة فحص الجودة (`QA Critic`) والمدير المالي الذكي (`CFO Guardrail`).
4. **محرك الربح المزدوج (`SaaS & API Manager`)**: دعم `OpenRouter` و`Gemini` و`OpenAI` وإدارة اشتراكات عملاء الـ SaaS.

## طريقة التشغيل على جهازك الشخصي
- **ويندوز (Windows):** اضغط مرتين على ملف `start.bat`
- **لينكس أو ماك (Linux / macOS):**
  ```bash
  chmod +x start.sh
  ./start.sh
  ```

## طريقة الرفع على سيرفر سحابي (VPS) للعمل 24/7 وبيعها كـ SaaS
```bash
docker compose up -d --build
```
سيعمل النظام بالكامل (الواجهة + الـ API + الجدولة الذاتية + روابط الـ Webhooks) على المنفذ `8000` مع حفظ دائم لقاعدة البيانات.
